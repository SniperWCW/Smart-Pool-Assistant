# Release Notes V3.0.22

## Messhistorie

- Die gemischte Messhistorie der Lovelace-Karte zeigt jetzt nur noch relevante Chemiewerte fuer `Chlor`, `pH` und `Cyanursaeure`.
- Temperaturwerte werden aus dieser kompakten Historie ausgefiltert, damit der Fokus auf den wasserchemischen Messungen bleibt.

## Doku und Demos

- README und Karten-Dokumentation wurden auf aktuelle `.png`-Screenshots umgestellt.
- Die Demo-Galerie zeigt jetzt den aktuellen Kartenstand fuer eingeklappte Bereiche, Wetter, Stabilitaet, Messungen, LayZSpa, Aktivitaeten und Wartungsstatus.
- Die technische Dokumentation beschreibt die aktuellen Status-/Nutzungsboxen und die API-Messwertetabelle konsistenter zum Frontend.

## Release-Artefakte

- `manifest.json`, `README.md`, `Changelog.md`, `TECHNISCHE_DOKUMENTATION.md` und diese Release Notes wurden auf `3.0.22` aktualisiert.
