# Release Notes V3.0.12

## Diagnose-Logging

- Verwarfene Chlor-Dosier-Samples aus der Reparatur- und Diagnoselogik werden jetzt als Info statt als Warning geloggt.
- Dadurch zeigt Home Assistant fuer fachlich verworfene Samples keine irrefuehrende Fehlerbox mehr an.
