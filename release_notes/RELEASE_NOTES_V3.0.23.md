# Release Notes V3.0.23

## Messhistorie

- Bereits gespeicherte Historieneintraege werden beim Mergen jetzt ebenfalls auf echte Chemieparameter bereinigt.
- Dadurch verschwinden alte Temperaturzeilen aus der kompakten Messhistorie nach dem naechsten Update sauber mit dem restlichen Verlauf.
- Die gemeinsame Historie bleibt quellenuebergreifend fuer `API`, `BLE` und `Manuell`, zeigt dort aber nur noch `Chlor`, `pH` und `Cyanursaeure`.

## Release-Artefakte

- `manifest.json`, `README.md`, `Changelog.md`, `TECHNISCHE_DOKUMENTATION.md` und diese Release Notes wurden auf `3.0.23` aktualisiert.
