# Release Notes V3.0.35

## LayzSpa-Fehleranzeige

- LayzSpa-Fehler werden bei einem relevanten Fehlercode nun direkt im sichtbaren Kopfbereich der Karte angezeigt.
- Die Warnung befindet sich nicht mehr ausschließlich im einklappbaren LayzSpa-Bereich und wird dadurch nicht übersehen.
- Bei Fehlercode `0` bleibt die Warnung weiterhin verborgen.
