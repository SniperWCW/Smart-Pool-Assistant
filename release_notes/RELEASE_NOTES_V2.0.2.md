# Release Notes V2.0.2

## Highlights

- Mobile Darstellung der aktuellen Messwerte verbessert.
- Wetter-Kopfzeile auf Handybreite korrigiert.

## Details

### Lovelace-Karte

- Die Messwerttabelle blendet auf schmalen Displays den Tabellenkopf aus und zeigt stattdessen kompakte Labels direkt an den Werten.
- Ist-, Ziel- und Quellenwerte bleiben dadurch auch mobil eindeutig zuordenbar.
- Die Wetter-Kopfzeile nutzt mobil ein zweizeiliges Layout: Titel und Pfeil oben, Wetterzusammenfassung darunter.
- Die Wetterzusammenfassung bricht sauber um, statt mitten im Inhalt ungünstig abgeschnitten zu werden.

### Dokumentation / Versionierung

- `README.md`, `TECHNISCHE_DOKUMENTATION.md`, `Changelog.md`, `manifest.json`, Frontend-Banner und diese Release Notes wurden auf `2.0.2` aktualisiert.
