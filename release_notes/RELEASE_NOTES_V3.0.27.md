# Release Notes V3.0.27

## Karte und Eingabelogik

- Die Vor-Baden-Empfehlung mit aktivem Badeplan sagt jetzt klar, dass die berechnete `chlor_pre`-Menge sofort zugegeben werden soll, damit der Mindestwert zum geplanten Badezeitpunkt passt.
- Nach einer erfassten pH-Zugabe sperrt die Karte nur noch die pH-Eingabe, nicht mehr zusaetzlich die Chlor-Erfassung.
- Nach einer erfassten Chlor-Zugabe sperrt die Karte nur noch die Chlor-Eingabe, nicht mehr zusaetzlich die pH-Erfassung.
