# Release Notes V3.0.24

## Messhistorie

- Persistierte Eintraege in `last_measurements_display` werden bereits beim Laden aus dem Storage bereinigt.
- Dadurch verschwinden alte Temperaturzeilen nach einem Reload oder Neustart, ohne dass erst neue Chemiemessungen geschrieben werden muessen.
- Der Abschnitt in der Karte heisst jetzt `Letzte 5 Chemie-Messwerte`, passend zum tatsaechlichen Inhalt.

## Release-Artefakte

- `manifest.json`, `README.md`, `Changelog.md`, `TECHNISCHE_DOKUMENTATION.md` und diese Release Notes wurden auf `3.0.24` aktualisiert.
