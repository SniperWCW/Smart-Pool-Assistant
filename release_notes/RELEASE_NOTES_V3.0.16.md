# Release Notes V3.0.16

## CYA-Prognose

- Der Prognosetext beschreibt sinkende oder steigende CYA-Werte jetzt als modellierten Netto-Effekt.
- Dadurch klingt die Anzeige nicht mehr so, als wuerde sich CYA im Normalfall einfach von selbst abbauen.

## Klarere Ursachen im Text

- Sinkende CYA-Werte werden im Prognosetext jetzt typischerweise mit dokumentiertem Wasserwechsel verknuepft.
- Steigende CYA-Werte werden typischerweise auf stabilisierte Chlorzugaben zurueckgefuehrt.

## Release-Artefakte

- `manifest.json`, `README.md`, `Changelog.md`, `TECHNISCHE_DOKUMENTATION.md`, `pool-chemistry-card.js` und diese Release Notes wurden auf `3.0.16` aktualisiert.
