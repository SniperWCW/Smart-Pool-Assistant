# Release Notes V3.0.13

## Integrations-Fixes

- Wetter-Forecasts greifen wieder bis in die Chemielogik durch, sodass UV-Zuschlag und Regen-Hinweise nicht mehr still ausfallen.
- Der BLE-Verbindungsstatus wird nach erfolgreichem PoolLab-Abruf wieder korrekt bis ins Frontend gespiegelt.
- Manuell eingetragene PoolLab-BLE-Adressen werden jetzt im Config Flow ebenfalls sauber dedupliziert.
- Bei mehreren Smart-Pool-Assistant-Eintraegen ordnet die Lovelace-Karte den PoolLab-Abruf-Button robuster dem passenden Sensor zu.

## Release-Artefakte

- `manifest.json`, `README.md`, `Changelog.md` und diese Release Notes wurden auf `3.0.13` aktualisiert.
