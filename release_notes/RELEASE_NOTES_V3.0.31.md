# Release Notes V3.0.31

## Karte und Nachmessung

- Unter `Warten auf erneute Messung` zeigt die Lovelace-Karte jetzt das gueltige Nachmessfenster direkt in der Statusbox an.
- Fuer Chlor nutzt die Karte exakt dieselben Start- und Endzeiten wie die bestehende Push-Mitteilung zur Dosierqualitaet.
- Die Zeitfenster werden dafuer zentral im Backend berechnet und als Attribute an die Empfehlungs-Entitaet weitergereicht.
