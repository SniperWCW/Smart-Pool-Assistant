# Release Notes V3.0.30

## Benachrichtigungen

- Direkt nach einer erfassten Chlorzugabe wird der redundante Hinweis auf eine noch fehlende Nachmessung nicht mehr zusaetzlich gesendet.
- Push-Benachrichtigungen erhalten jetzt automatisch passende `tag`- und `group`-Werte fuer feinere Gruppierung nach Ereignistyp.
- Wartungsaktionen und Nachmess-Erinnerungen werden dafuer intern nach Chlor, pH-Plus, pH-Minus, Wasserwechsel, Filterreinigung, Filterwechsel und Chlor-Sample-Zustand getrennt behandelt.

## Release-Artefakte

- `manifest.json`, `README.md`, `Changelog.md`, `TECHNISCHE_DOKUMENTATION.md`, Frontend-Versionshinweis und diese Release Notes wurden auf `3.0.30` aktualisiert.
