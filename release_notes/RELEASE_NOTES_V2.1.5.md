# Release Notes V2.1.5

## Highlights

- Status und Badeampel erscheinen jetzt als eine gemeinsame Box mit zwei Spalten.
- Die Darstellung bleibt fachlich getrennt, wirkt aber ruhiger und kompakter.

## Details

### Lovelace-Karte

- Die obere Statusfläche besteht jetzt aus einer gemeinsamen Karte.
- Links steht `Status`, rechts steht `Baden`.
- Der Außenrahmen und Hintergrund richten sich nach dem kritischsten Zustand.
- Auf mobilen Ansichten werden die beiden Bereiche innerhalb derselben Box untereinander angezeigt.

### Dokumentation / Versionierung

- `README.md`, `TECHNISCHE_DOKUMENTATION.md`, `Changelog.md`, `manifest.json`, Frontend-Version und diese Release Notes wurden auf `2.1.5` aktualisiert.
